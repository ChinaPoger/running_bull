# Mobile-web art credits

Sprites for the portrait game under `mobile-web/`. `game.js` loads these paths and draws a canvas placeholder only if a file fails to load.

## Characters

`forest/bull_0.png` … `bull_4.png`, `deer_0.png` … `deer_4.png`, `dog_0.png` … `dog_4.png`

Original rear three-quarter run cycles (four strides plus a jump). The bull uses the same warm brown, cream, and red-collar palette as the landscape runner in `public/assets/bull_run*.png`. Deer and dog are original and drawn in that same sticker style.

## Forest map

`forest/forest_backdrop.png`, `forest/forest_road.png`, `tree_quat_common_1.png`, `tree_quat_common_3.png`, `tree_quat_pine_1.png`, `tree_quat_pine_3.png`, `tree_quat_twisted_1.png`, `bush_quat_flowers.png`

Original flat cartoons. The `tree_quat_*` / `bush_quat_*` filenames are the keys `game.js` already requests. They are not Quaternius models and are not copied from that pack.

## Kenney trees

`forest/tree_kenney_007.png`, `tree_kenney_010.png`, `tree_kenney_016.png`, `tree_kenney_pine.png`

From Kenney's Foliage Pack (retina PNGs `foliagePack_007`, `_010`, `_016`, and `_012`), by Kenney Vleugels (www.kenney.nl).

License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The pine's snow caps were recolored to sunlit green so the tree sits in this forest. Credit to Kenney is appreciated and not required.

## Plant mode

`sunflower.png`, `peashooter.png`, `gatling.png`, `cherry_bomb.png`, `wallnut.png`, `zombie_basic.png`, `sun_token.png`, `lawn_backdrop.png`

Original cartoons in the same sticker style. They are a homage to the plant-versus-zombie idea and are not PopCap, EA, or Plants vs. Zombies artwork.

## Plane mode

`plane/fighter.png`, `enemy_small.png`, `enemy_big.png`, `bullet.png`

Original cartoons. The fighter points up the screen (away from the camera); enemies point down toward the runner.
