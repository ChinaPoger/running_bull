关于「大角牛快跑 · 竖屏跑酷」

勇敢牛牛，不怕困难。

竖屏三道跑酷 · 静态页面在 /mobile-web/ · 可在手机浏览器打开

这是什么

大角牛快跑的竖屏网页版：选角色（大角牛 / 小鹿 / 小狗），选地图（土路、优美森林、植物跑酷、悬空空间、飞机大战、慢慢跑酷），左右换道、跳跃与滑铲躲障，捡金币。横版原型仍在网站根路径，两种玩法共用同一套 /api 钱包。跑完的竖屏成绩保存在服务器上，大厅里能看到最近几局。

打开页面就会用本机设备号进入账号，不用点登录。同一浏览器会记住金币和成绩；清除本站数据会换成新账号；换一部手机是另一个账号。昵称可以改，身份仍是这个设备号。

怎么玩

  • 左右滑或 ◀▶：换道
  • 上滑 /「跳」/ 点屏幕上半：起跳
  • 下滑：滑铲
  • 💣 清当前道；🛡️ 无敌冲撞；⚡ 短冲刺
  • 飞机大战：默认扫射，左右换道躲弹、打大小怪
  • 撞障时弹出激励广告示意（本地约 2 秒占位，不是真实广告）

广告、抽奖和钱包

  • 展示广告位默认关闭，页面不加载任何广告脚本，也不需要广告或支付 SDK。
  • 激励视频是本地占位：看完继续跑，连续跳过两次则结算。
  • 抽奖 / Top3 红包是活动示意 / 非赌博，只在本机模拟，不会发钱。
  • 本局金币在连上服务器时记入和大角牛横版同一个钱包（按服务器的每秒上限封顶）。竖屏得分记在本机排行榜，不覆盖全服最高分。

怎么打开

本地：在 running_bull_web 里运行 python3 server.py，浏览器打开 http://127.0.0.1:3000/mobile-web/。线上路径：https://bull.lingecho.com/mobile-web/。

代码：github.com/ChinaPoger/running_bull。
