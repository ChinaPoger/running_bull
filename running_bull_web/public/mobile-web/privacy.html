隐私政策

最后更新：2026-10-25 · 适用于大角牛快跑竖屏页（/mobile-web/）

本页说明竖屏跑酷如何处理信息。游戏页面是静态文件；若和横版一样由 bull.lingecho.com 提供，金币和昵称会走已有的 /api。没有接入广告 SDK 或支付 SDK。

1. 存在这台设备上的数据

  • 本机角色和昵称：选中的角色、演示昵称和头像 URL，保存在浏览器 localStorage。全服排行榜在服务器上，不存在本机榜里。
  • 设备号：rb_device，同时放在 localStorage 和同名 Cookie 里，和横版网页共用。这是账号本身。两份都在时以本地存储为准；只剩一份时用它把另一份补回来。

2. 会发给服务器的数据

  • 打开页面时：设备号，以及地址栏里的邀请码（如果有），用于创建或读取这个本机账号。不需要再点登录。
  • 同时会发送 client_hint：由浏览器类型、屏幕尺寸、语言和时区算出的短哈希。服务器只把它记在账号旁边，不用它认出你是谁。没有设备号就不会登录。
  • 开局 / 结算：分数、金币、距离、时长、角色和地图。竖屏得分记在你的账号下，不写入横版全服最高分。
  • 你在「改昵称」里保存的昵称。那里填的头像 URL 只留在本机。

服务器连不上时，游戏仍可在本机玩，上述同步会跳过。

3. 我们不做什么

  • 不加载广告脚本，展示广告位保持关闭。
  • 撞障「激励视频」是本地倒计时，不上传观看记录。
  • 不发放红包，也不做现金奖励。
  • 竖屏页不提供微信登录。公众号授权接口默认关闭，密钥不会出现在网页里。

4. 托管与日志

静态文件由网站服务器（当前为 nginx）直接提供，/api/ 转到本机游戏后端。服务器可能按常规记录访问日志（IP、浏览器、路径）。

5. 你的选择

可在浏览器里清除本站数据。本地存储和 Cookie 都清掉后，会生成新的设备号，也就是一个新账号。服务器上旧设备号的金币和成绩还在，但这个浏览器已经没有那串字符，页面认不回来。换一部手机也是另一个账号。

6. 儿童

本游戏是休闲试玩。若你未满当地数字服务法定年龄，请在监护人指导下使用。
