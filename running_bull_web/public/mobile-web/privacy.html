隐私政策

最后更新：2026-10-25 · 适用于大角牛快跑竖屏页（/mobile-web/）

本页说明竖屏跑酷如何处理信息。游戏页面是静态文件；若和横版一样由 bull.lingecho.com 提供，金币和昵称会走已有的 /api。没有接入广告 SDK 或支付 SDK。

1. 存在这台设备上的数据

  • 本机排行、角色、抽奖示意：得分榜、游玩时长、演示昵称和头像 URL、抽奖状态，保存在浏览器 localStorage。
  • 设备号：rb_device，和横版网页共用，用来识别同一个游客账号。

2. 会发给服务器的数据

  • 打开页面时：设备号，以及地址栏里的邀请码（如果有），用于创建或读取游客账号。
  • 开局 / 结算：本局捡到的金币数量。竖屏得分不会写入全服最高分。
  • 你在「设置昵称（演示）」里保存的昵称。头像 URL 只留在本机，不上传。

服务器连不上时，游戏仍可在本机玩，上述同步会跳过。

3. 我们不做什么

  • 不加载广告脚本，展示广告位保持关闭。
  • 撞障「激励视频」是本地倒计时，不上传观看记录。
  • 抽奖和 Top3 红包是示意 / 非赌博，不产生真实支付。
  • 没有微信登录。演示昵称不是微信账号。

4. 托管与日志

静态文件由网站服务器（当前为 nginx）直接提供，/api/ 转到本机游戏后端。服务器可能按常规记录访问日志（IP、浏览器、路径）。

5. 你的选择

可在浏览器里清除本站数据。清除后本机排行和设备号会重置；服务器上已记入钱包的金币仍挂在旧设备号上，除非后台另行删除。

6. 儿童

本游戏是休闲试玩。若你未满当地数字服务法定年龄，请在监护人指导下使用。
