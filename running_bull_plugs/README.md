# 大角牛快跑 · 竖版（running_bull_plugs）

背后视角的三车道竖向跑酷：大角牛在画面下方背对着你往前跑，三条车道（左 / 中 / 右）伸向远处的地平线，障碍、金币从远处（小）迎面跑来（越来越大）。

## 画面尺寸说明
XBuilder 的运行窗口固定是 4:3（480×360，电脑和手机都一样），更高的竖屏舞台会被裁掉上下两截。
所以 v2 把舞台改成 480×360：玩法还是“竖着跑”的三车道（赛道从下往上伸向远处），整个画面在 XBuilder 里能完整显示，手机上也能点到所有按钮。
分数、金币、钱包、排名、昵称、PIN、提示全部画在游戏画面里，不再用 XBuilder 的变量监视器。

## 文件
- `running_bull_plugs.xbp`：在 XBuilder 里直接导入这个文件
- `project/`：工程源码（spx 代码 + 素材），和 xbp 里的内容一样

## 操作
| 动作 | 键盘 | 手机 / 鼠标 |
|---|---|---|
| 换车道 | ← / → 或 A / D | 左右滑 |
| 跳跃（低栏、石堆） | ↑ / W / 空格 | 上滑 |
| 滑铲（高门） | ↓ / S | 下滑 |
| 草垛、木箱 | 只能换道躲开 | 左右滑 |
| 开始 / 再来一局 | 空格 / 回车 | 点屏幕 |
| 商店 | B | 点「商店」 |
| 账号 / 重新登录 | L | 点「账号」 |

## 和横版一样保留的功能
金币、闪电冲刺（无敌 + 吸金币）、音效和背景音乐、商店（3 个角色、3 张地图、无敌护盾、双倍金币）、撞车后复活一次（花 100 金币或看示意广告）、新纪录提示；
在线账号（昵称 + 4 位 PIN，和横版**共用**同一个服务器 https://bull.lingecho.com/api 和同一批账号），也可以「游客试玩」（不联网、不存档）。
联网请求都在后台进行，不会卡住画面；浏览器控制台里带 `[bull]` 的日志可以看到每次请求的情况。
